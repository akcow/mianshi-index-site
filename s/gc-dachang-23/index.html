1.C++20 引入了哪些重要新特性？

C++20 主要新增了协程、概念（Concepts）、范围库（Ranges）、三路比较运算符<=>、模块（Modules）预览，还有改进的 constexpr、lambda 捕获等。我重点用过协程做异步网络调用，概念则用来约束模板参数提升可读性。

  1. 准确列出至少4项核心特性
  2. 能区分语法糖与范式级改进（如协程vs三路比较）
  3. 说明1项在服务端开发中的潜在用途

2.emplace_back 和 push_back 有什么区别？

vector 扩容时先申请新内存，拷贝/移动旧元素，再释放旧内存。选1.5或2倍是为了保证摊还时间复杂度为O(1)：太小会导致频繁拷贝，太大浪费内存。1.5倍是平衡内存碎片和拷贝开销的常见折中。

回答要点
  1. push_back 接受已构造的对象，可能发生一次拷贝或移动
  2. emplace_back 接受构造参数，在容器内存上原地构造，省掉临时对象
  3. emplace 用完美转发，但对 explicit 构造和花括号初始化列表有坑
  4. 并非永远更快：传入已是同类型对象时两者开销相同
完整解析（含追问与踩坑）→
3.std::string_view 的设计目的和使用边界是什么？

string_view 是轻量级只读字符串视图，不拥有数据，只存指针和长度，用于避免不必要的 string 构造和拷贝。但必须确保它引用的原始字符串生命周期长于 view 本身，否则会悬垂。

回答要点
  1. 明确‘非拥有’和‘零拷贝’特性
  2. 指出核心风险是悬垂引用
  3. 举例适用场景（如函数参数）和禁用场景（返回局部字符串view）
完整解析（含追问与踩坑）→
4.左值和右值的本质区别是什么？请结合面试官写的代码判断能否编译。

左值是有身份、可取地址的表达式，比如变量名；右值是临时对象或字面量，不可取地址但可移动。判断编译性关键看绑定规则：非const左值引用只能绑左值，const左值引用和右值引用可绑右值。

回答要点
  1. 定义左值=有标识+可取地址，右值=无标识+可移动
  2. 说出三种引用绑定限制（T&/const T&/T&&）
  3. 能根据代码中表达式类型推导绑定结果
完整解析（含追问与踩坑）→
5.结构体的内存对齐规则是什么？请分析嵌套结构体的总大小。

对齐规则是：结构体自身对齐值等于其最大成员对齐值；每个成员按自身对齐值偏移；结构体总大小是自身对齐值的整数倍。嵌套时，内层结构体作为成员，按其对齐值对齐，再计算外层填充。

回答要点
  1. 复述三条基本规则（自身对齐/成员偏移/总大小）
  2. 能手算给定嵌套结构体的大小
  3. 指出#pragma pack的影响是降低对齐要求
完整解析（含追问与踩坑）→
6.虚拟地址空间的寻址过程是怎样的？请从CPU发出地址到访问物理内存完整说明。

CPU生成虚拟地址，经MMU查TLB缓存页表项；若TLB miss，则查多级页表（如x86_64四级），得到物理页框号；再拼上页内偏移，形成物理地址访问内存。缺页时触发异常，OS分配页框并更新页表。

回答要点
  1. 明确TLB是页表缓存，命中则直接得物理地址
  2. 说出多级页表层级（如PGD→PUD→PMD→PTE）
  3. 指出缺页异常由OS处理，非硬件自动完成
完整解析（含追问与踩坑）→
7.请口述算法思路：给定01数组，反转一个连续子区间，使得反转后整个数组中1的个数最多。

反转区间相当于把区间内0变1、1变0，所以1的增量 = 区间内0的个数 - 1的个数。令新数组b[i]=1 if a[i]==0 else -1，问题转为求b的最大连续子数组和。用Kadane算法一次遍历，记录最大和及左右端点即可。

回答要点
  1. 正确建模为‘0增1减’的收益数组
  2. 指出转化后等价于最大子段和
  3. 说明O(n)时间实现及如何还原原区间
完整解析（含追问与踩坑）→
8.epoll 为什么比 select/poll 更高效？请从底层原理说明。

epoll 用红黑树管理监听fd，用就绪链表存活跃事件，每次wait只返回就绪fd，避免遍历全部fd；而select/poll每次都要传入全量fd集合并线性扫描。epoll_ctl注册一次，后续wait零拷贝，大幅降低用户态/内核态交互开销。

回答要点
  1. 指出epoll维护就绪链表，避免O(n)扫描
  2. 说明epoll_ctl注册后内核持久化管理fd
  3. 对比select/poll每次需拷贝fd_set和线性检查
完整解析（含追问与踩坑）→
9.在射击游戏中，从子弹发射到击中玩家，服务器需要存储哪些关键状态数据？

必须存：子弹唯一ID、发射者ID、目标ID（若锁定）、初始位置/速度/方向、发射时间戳、生存时间、碰撞检测所需属性（如射程、穿透数）。不需要存每帧位置，而是用时间+运动学公式实时推算，减少带宽和存储。

  2. 说明为何不存完整轨迹而用公式推算
  3. 指出时间戳用于客户端插值和服务器回滚校验

10.如何设计一个支持单机50万玩家并发的游戏服务器架构？

核心是分而治之：用连接层（如DPDK）卸载网络；逻辑层按世界/区域分服分片，每服承载2-5万玩家；状态用Redis Cluster缓存热数据，MySQL分库分表存持久化；关键操作如战斗用消息队列削峰，配合乐观锁防超卖。单机瓶颈在CPU，需协程+无锁队列压榨性能。

  3. 说明状态存储选型依据（缓存热数据+DB持久化）
