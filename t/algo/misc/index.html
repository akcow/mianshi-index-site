[等差数列划分（力扣 413）]

定义dp[i]为以i结尾的等差子数组个数。转移方程：如果nums[i]-nums[i-1]==nums[i-1]-nums[i-2]，则dp[i]=dp[i-1]+1，否则dp[i]=0。初始化dp[0]=dp[1]=0，答案是sum(dp)。关键点是连续三个数才能构成等差，所以i从2开始。

解释一下 `O(1)`、`O(n)`、`O(log n)`、`O(n^2)`，并举例场景。

O(1) 是常数时间，比如数组按索引取值；O(n) 是线性，比如遍历找最大值；O(log n) 是对数，比如二分查找；O(n²) 是平方，比如冒泡排序或矩阵乘法。重点看操作次数是否随输入规模增长而倍增。

回答要点
  1. 每个复杂度配一个无争议经典例子
  2. 例子必须体现‘操作次数与 n 的关系’
  3. O(1) 必须是非迭代/非递归的确定性操作

前缀表达式求值时，如果遇到非法 token（比如字母），你的程序怎么处理？

我会在解析 token 时做类型校验：非运算符且不能转整数，就立即返回 error，带明确定位信息，比如‘token at index 5 “abc” is invalid’。不静默跳过，也不用 panic，因为这是输入错误，不是程序 bug。上层可以据此拒绝整个表达式，避免后续计算污染。

回答要点
  1. 对非法 token 主动校验并提前失败
  2. error 信息包含位置和具体内容
  3. 不 panic、不忽略、不继续执行

堆排序。

分两步：先自底向上 heapify 建最大堆；再循环把堆顶和末尾交换，然后对新堆顶下沉调整。关键细节：父节点索引是 (i-1)/2，左子是 2*i+1；下沉时要比较左右子并选大者交换；数组下标从 0 开始，别越界。

回答要点
  1. 正确实现 heapify 下沉逻辑
  2. 交换后能维持剩余堆性质
  3. 边界处理无数组越界

三个线程分别打印a、b、c，多线程打印abc五遍

用一个volatile int state标记当前该谁打印，初始为0；每个线程while循环检查state，等于自己序号就打印并state++模3，否则yield让出CPU。关键要加volatile保证可见性，避免死循环。

回答要点
  1. state变量用volatile修饰确保线程可见
  2. 使用模3运算实现循环轮转（0→1→2→0）
  3. 打印后原子更新state，避免竞态

数组A中给定可以使用的1~9的数，返回由A数组中的元素组成的小于n的最大数。例如A={1,2,4,9}，n=2533，返回2499。

从高位开始贪心：每位尝试填A中≤当前位的最大数；如果填了等于当前位的数，继续下一位；如果填了更小的数，后面全填A中最大值；关键在‘填更小数后能否补足位数’——若A中无数字，直接失败；若位数不够，需向前回溯，把上一位换成更小的可选数，再补满。

回答要点

  2. 处理位数不足时的向前回溯
  3. 边界：A为空或全0时返回-1

请介绍布隆过滤器。

布隆过滤器是一种用位数组加多个哈希函数实现的快速存在性判断结构。添加元素时，多个哈希值对应位置设为 1；查询时，所有哈希位置都是 1 才认为‘可能存在’。它不存原始数据，所以空间极小，但有误判率，且无法删除元素。常用于缓存穿透防护或大数据去重预筛。

回答要点
  1. 说明位数组+多哈希函数的核心结构
  2. 准确表述‘存在则必存在，不存在可能误判’的特性
  3. 举出至少一个典型应用场景（如缓存穿透防护）

字符串处理 2 题

根据字符串中的数字重新排序

遍历每个字符串，逐字符扫描，遇到数字就拼成整数，没数字就设为 0。然后按这个数字升序排序，数字相同时保持原顺序（用 stable sort）。关键点是：数字提取要连续拼接，比如 ‘a2b3’ 提取 23，不是 2 和 3；空字符串或纯字母返回 0。

回答要点
  1. 正确提取连续数字字符并转为整数（如 'ab2cd3' → 23）
  2. 无数字字符串返回 0
  3. 使用稳定排序保证相同数字的原始顺序
  4. 能处理边界：空字符串、纯字母、前导零（如 'a01b' → 1）
完整解析（含追问与踩坑）→
不用库函数实现字符串转整数，需要考虑正负号、非法字符和溢出。

先跳过空格；记录符号；遍历数字字符，每步用 result = result * 10 + digit；溢出检查：if (result > INT_MAX/10 || (result == INT_MAX/10 && digit > 7)) 就返回 INT_MAX 或 INT_MIN。注意负数溢出是 -2147483648，digit > 8 才越界。

回答要点
  1. 跳过前导空格，识别 '+'/'-' 符号
  2. 逐字符转换，及时检测溢出：对正数 check result > (INT_MAX - digit)/10
  3. 正确处理 INT_MIN = -2147483648（-2^31，比 INT_MAX 绝对值大 1）

栈 2 题

前缀表达式如何求值？请从右向左扫描并用栈实现。

从右往左扫：遇到数字就压栈；遇到运算符就弹两个数——注意顺序，先弹的是左操作数，后弹的是右操作数，比如‘-’要算 a-b；算完结果再压栈。最后栈里只剩一个数就是答案。要检查栈大小，避免弹空或剩多个，还要判除零。

回答要点
  1. 明确扫描方向为从右向左
  2. 弹出两个操作数时顺序正确（先弹左，后弹右）
  3. 有基础错误处理（栈空、除零、最终栈元素数≠1）
完整解析（含追问与踩坑）→
前缀表达式求值栈实现中，为什么弹出的两个数，第一个是左操作数、第二个是右操作数？

因为前缀是 operator operand1 operand2，从右往左扫时，operand2 先入栈，operand1 后入栈。弹出时 operand1 先出（栈顶），operand2 后出（次栈顶）。比如 ‘- 5 3’，右扫得 [3,5]，弹 5 再弹 3，算 5-3，顺序才对。

回答要点
  1. 明确前缀语法结构 operator op1 op2
  2. 说明从右向左扫描导致 op2 先入、op1 后入
  3. 弹出顺序与运算顺序严格对应（先弹左，后弹右）

滑动窗口 2 题

滑动窗口最大值
回答要点
  1. 单调递减双端队列，队首即窗口最大值
  2. 入队前弹出所有小于当前值的元素，队首超出窗口则弹出
  3. O(n) 时间复杂度
展开讲讲
单调递减双端队列的设计本质是用空间换确定性时间：每个元素至多入队、出队各一次，因此总操作数 ≤ 2n，均摊 O(1) 每次操作。若改用普通队列或数组维护窗口内元素，每次求最大值需 O(k) 扫描，滑动 n−k+1 次则退化为 O(nk)，k 接近 n 时达 O(n²)（《算法导论》第6版 6.5.1 节明确分析堆/线性结构在滑动窗口中的摊还代价）。若用堆（如 heapq），虽支持 O(log k) 插入和删除，但无法高效删除任意位置的过期元素——需延迟删除或标记，导致堆尺寸膨胀至 O(n)，最坏插入仍为 O(log n)，总复杂度 O(n log n)（Python 官方文档：heapq 模块说明指出其不支持 O(1) 删除任意元素）。最小示例：deque = collections.deque(); for i, x in enumerate(nums): while deque and nums[deque[-1]] < x: deque.pop(); deque.append(i); while deque and deque[0] <= i - k: deque.popleft() —— 其中 pop() 和 popleft() 的调用次数总和严格 ≤ 2n（CLRS 17.2 摊还分析标准范式）。
